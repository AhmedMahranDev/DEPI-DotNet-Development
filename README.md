## About This Repository

This repository documents my progress in software development through practical exercises, code implementations, and projects developed during the DEPI .NET training journey.

The focus is on understanding programming fundamentals, applying object-oriented principles, writing maintainable code, working with databases, and building web applications using the .NET ecosystem.

Rather than collecting code alone, this repository aims to demonstrate how concepts are applied, tested, improved, and organized throughout the learning process.

## Learning Roadmap

### 01. C# Fundamentals
- Variables, Data Types, and Operators
- Conditions and Loops
- Arrays and Array Operations
- Methods and Parameters
- Structs, Classes, and Objects
- Properties, Constructors, and Indexers
- Searching, Adding, Updating, and Removing Data
- Dynamic Array Resizing

### 02. Object-Oriented Programming (OOP)
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Object Relationships and Code Reusability

### 03. Entity Framework Core
- Database Modeling and Entity Relationships
- Code-First Approach
- Migrations and Database Management
- CRUD Operations
- Working with Relational Data

### 04. LINQ
- Filtering and Projection
- Sorting and Grouping
- Aggregate Operations
- Joins and Relationships
- Querying Collections and Database Data

### 05. ASP.NET Core Web API
- RESTful API Fundamentals
- Controllers, Routing, and HTTP Methods
- Request and Response Handling
- DTOs and Validation
- Dependency Injection
- Database Integration

### 06. ASP.NET Core MVC
- Models, Views, and Controllers
- Razor Views
- Forms and Model Binding
- Validation
- Database-Driven Web Applications
- Application Structure and Separation of Concerns
